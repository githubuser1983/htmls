Compile TM JSON · Variable-Order-Markov-TM

Für jede Ordnung n=1…N werden Markov-Zustände aus tatsächlich vorkommenden n-Grammen gebaut. Die fertige TM vereinigt alle Ordnungen. Nach jedem gelesenen Zeichen nimmt sie den längsten bekannten Suffix-Kontext; wenn er fehlt, fällt sie n→n−1→…→1 zurück. Der Root-Zustand ist Startzustand und führt für jedes Zeichen des Trainingsalphabets direkt in den passenden n=1-Zustand.

n=1 wird vollständig aufgenommen, damit Root für jedes bekannte Zeichen definiert ist. Für n≥2 werden die häufigsten n-Gramm-Zustände genommen, bis mindestens die gewählte Auftretensmasse dieser Ordnung abgedeckt ist; notwendige Suffix-Zustände werden zusätzlich aufgenommen. Das ist keine Next-Character-Vorhersage: das aktuelle Zeichen wird gelesen und bestimmt den Folgezustand.
