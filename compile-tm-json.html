Compile TM JSON · kurze n‑Gramme bis Ziel-Texttreue

Diese Stufe baut nur die klassische deterministische Text-TM. Gemessen wird billig und eindeutig: an jeder Textposition sieht das Modell den wahren bereits gelesenen Präfix; aktiv ist der längste ausgewählte Suffix-Kontext und dessen häufigster nächster Buchstabe wird geprüft. Das ist Teacher-Forced Next-Character-Accuracy, nicht autonome Vollkopie.

AUTO nimmt zuerst das kleinste n, mit dem das Ziel überhaupt erreichbar ist. Danach wird ein suffix-geschlossener Kontextbaum budgetiert: kurze Kontexte müssen vor längeren vorhanden sein; bevorzugt werden Äste mit hohem zusätzlichem Fehlergewinn. Q ist die tatsächlich gewählte Zustandszahl. N ist minimal für die gewählte Genauigkeitsmetrik; Q ist greedy klein, nicht als globales Minimum bewiesen.
Bereit.
Ausgabe: …-p95-nN-qQ.tm.json.gz. Die ReLU-Stufe soll anschließend 100 % der Übergänge dieser TM lernen. Der Quelltext wird nur zur Auditierbarkeit im Artefakt mitgeführt; die ReLU benötigt ihn nicht.
